# 3D Tank Expanded

A 3D physics-based game where the player controls a tank on a battlefield made with a 3D terrain: hills, trenches, craters, ruined walls, dirt tracks and woods. The tank has an independently aimed turret. Firing launches a shell that follows the turret's angle and inclination and explodes on the ground, the walls or the targets. Stationary enemy targets can be shot and react realistically to explosions, which are visualized with 3D particle effects and screen shake. A third-person camera follows the tank. The game supports both keyboard and mobile controls.
