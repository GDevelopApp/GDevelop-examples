# 3D Horror House Escape Expanded

A 3D physics-based first-person horror escape game in a dark, furnished two-story house made of 3D boxes: a living room, a kitchen, a study and a storage room with pushable crates downstairs, bedrooms and a dressing room upstairs, linked by a staircase, and a fenced yard outside. The rooms have old semi-realistic furniture (beds, sofa, cupboards, a grandfather clock, oil lamps). The player only sees what the flashlight lights, and must find the key hidden in the house to unlock the front door, then escape through the gate of the yard. A monster roams both floors using navmesh pathfinding, climbing the stairs and finding its way through the rooms; it uses raycasting to check if the player is in its line of sight, then chases them, and the game resets if it catches the player. The player cannot fight back. It suits haunted house, escape and hide-and-seek horror games. The game supports both keyboard/mouse controls and mobile touch controls.
