# UI prefabs

Every UI prefab of the asset store in several styles, side by side: one scene per prefab.

Each scene shows a prefab in three styles from the asset store, a flat white "Placeholder" style with a black outline to block out an interface before its art is ready, and a "Pixel art" style. Every style is a variant of the prefab, so an object switches style by changing its variant, and a new style starts by duplicating an existing variant.

The scenes are: button, slider, toggle switch, continuous resource bar, resource bar with separated units, text input, multitouch joystick, two choices dialog box, game over dialog, volume settings, animated score counter, star rating bar and multiplayer avatar.
