# 3D Platformer Expanded

A 3D physics-based platformer in a valley made with a 3D terrain: dirt paths winding up hills, platforms on their tops, coins along the way, a pond and woods. The player controls a character that can move, jump and fall, push a 3D physics box, jump on static boxes and collect coins. A third-person camera follows behind the player, but can also be manually controlled. The game supports both keyboard and mouse controls as well as mobile touch controls.
