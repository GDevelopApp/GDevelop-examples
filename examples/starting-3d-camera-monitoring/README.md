# 3D Camera switching horror

A 3D first-person starter game where you monitor security cameras inside of a dark building. Switch between cameras with on screen controls, that work for both mouse/keyboard or touchscreen mobile controls and monitor the building while watching the time remaining on the clock. The game features static effects and a VHS style retro camera overlay, and room checkers that help with managing the objects in each room.

A simple starting point for creating a camera switching horror game inspired by games like I'm on Observation Duty.
