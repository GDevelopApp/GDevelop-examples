# 3D Racing Expanded

A 3D car racing game with a third-person camera view, on a race track made with a 3D terrain: a start straight with grandstands and pits, a climb up a hill, hairpins and a descent through a wooded valley. The player accelerates and steers using keyboard or mobile controls, and the car uses physics-based movement. Checkpoints along the track count completed laps and measure lap times, and the UI displays the current lap number and most recent lap time.
