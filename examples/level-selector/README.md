# Level selector

Choose a level on a grid of levels or on a world map, win it with up to 3 stars to unlock the next one, and find the progress again the next time the game is opened.

The two level selectors are made with the "Level selector" extension. They read the same progress, kept in a global variable and saved in the storage: the number of unlocked levels and the stars of each level. Choosing a level opens the scene of the level, which saves the stars won and unlocks the next level.
