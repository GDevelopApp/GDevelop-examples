# 3D First Person Multiplayer Haunted House

A 3D physics-based first-person multiplayer horror game where the players can look around and turn using the camera, as well as jump and fall within the environment. Set indoors in a dark environment, the game features a flickering light with sound effects, creating an eerie atmosphere. A monster is positioned to jumpscare and kill the player that enters a designated collision detection area. Featuring a dimly lit hallway, and a dark cloudy night skybox that can be seen through a window, to establish the horror setting. Handling multiplayer controls and events using GDevelop's built in multiplayer behavior and lobbies. This is a small starter project featuring basic first-person controls, a simple jumpscare mechanic, and atmospheric lighting and sound effects, ideal for creating first person horror games like Amnesia: The Dark Descent, Outlast, and Silent Hill P.T..
